# Athletistry visual redesign — Phase 1

This branch keeps the existing Supabase, auth, workout, program and Stripe logic intact and replaces the primary visual system.

## Updated
- Global design tokens and polished-stone page background
- Editorial serif display typography with clean sans UI typography
- Desktop navigation/sidebar
- Mobile top bar, search and floating bottom tab bar
- Shared page headers, buttons, fields, cards and badges
- Dashboard information hierarchy and today's-session hero
- Achievement and daily inspiration cards
- Dashboard warm-up / exercise section hierarchy

## Design direction
Pale stone, graphite, restrained royal blue, thin rules, editorial scale, subtle dimensional surfaces and fewer competing cards. The goal is a premium ballet training studio / publication rather than a generic fitness SaaS interface.

## Backend safety
No Supabase schemas, migrations, auth logic, Stripe logic, program algorithms or data-fetching APIs were intentionally changed in this phase.
